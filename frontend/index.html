❓ Como Usar o LeadHunter

🔍 Realizando uma Busca

  1. Vá em Nova Busca
  2. Digite o tipo de negócio (ex: "clínicas odontológicas")
  3. Digite a cidade (ex: "Belo Horizonte - MG") — pode digitar várias, uma por linha
  4. Escolha entre Modo Normal (com email) ou Modo Rápido (sem email, 3–5× mais veloz)
  5. Ajuste o número de resultados com o slider
  6. Clique em Iniciar Busca e acompanhe em tempo real

⬇️ Exportando os Leads

  • CSV: Clique em "Exportar CSV" — o arquivo abre direto no Excel (UTF-8)
  • Excel: Exporta com formatação profissional (cores, hiperlinks, estrelas de avaliação)
  • Google Sheets: Clique em "Google Sheets" — siga as instruções de autenticação na primeira vez
  • Você pode selecionar apenas alguns leads antes de exportar

📊 Google Sheets — Primeira Configuração

  1. Acesse: console.cloud.google.com
  2. Crie um projeto → Ative Google Sheets API e Google Drive API
  3. Crie uma credencial OAuth 2.0 (App para Computador)
  4. Baixe o JSON e salve como credentials.json na pasta credentials/
  5. Na próxima exportação, uma janela abrirá para autorizar — é só uma vez!

⚠️ Dicas Importantes

  • Seja específico na busca: "lava-jatos" em "Contagem - MG" traz melhores resultados
  • Limite de 500 leads por busca para evitar bloqueio do Google
  • Se aparecer CAPTCHA, o scraper pausa automaticamente
  • Use o Modo Rápido quando não precisar de email/redes sociais
  • O campo "Status" em cada lead ajuda a controlar o pipeline de contatos
